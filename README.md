Title
# 📈 FutureFund AI

An AI-powered personal finance and investment planning application built using FastAPI, Streamlit, and SQLite.

Features
## Features

- Secure User Authentication
- Financial Dashboard
- SIP Calculator
- Lump Sum Calculator
- Inflation Calculator
- CAGR Calculator
- Goal Planner
- Portfolio Allocation Advisor
- AI Financial Advisor
- Financial Health Score
- Interactive Plotly Charts
- PDF Financial Report
- CSV & Excel Export
- Investment History

Tech Stack
## Tech Stack

Frontend:
- Streamlit

Backend:
- FastAPI

Database:
- SQLite

Libraries:
- Plotly
- Pandas
- NumPy
- ReportLab
- OpenPyXL
- Passlib
- BCrypt
